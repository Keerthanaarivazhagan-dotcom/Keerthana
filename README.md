Data Analytics Mini Project

Project Overview

This project focuses on analyzing retail sales and inventory data using Microsoft Excel and Power BI.

Project Objectives

Clean and preprocess the raw dataset using Excel.
Handle missing values, duplicates, incorrect formats, and data inconsistencies.
Create calculated fields and perform basic data analysis.
Build an interactive Power BI dashboard for sales and inventory analysis.
Present key insights through visualizations and KPIs.
Tools Used

Microsoft Excel
Microsoft Power BI
Dataset

The project uses retail sales and inventory data containing transaction, product, sales, return, and inventory-related information.

Project Work

Data Pre-processing
The raw data was cleaned and prepared in Excel by checking duplicates, missing values, data types, date formats, and inconsistencies.

Data Analysis
Key metrics such as total sales, quantity sold, cost of goods sold, gross profit, transactions, returns, and return percentage were analyzed.

Power BI Dashboard
The cleaned data was modeled and visualized in Power BI using KPIs and interactive charts to analyze sales and inventory performance.
